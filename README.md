# Chronicles of the Ossuary — download

Turn-based pixel roguelike for Windows. Beta.

## Install

1. Open the **[Releases](../../releases/latest)** page.
2. Download **`Ossuary_Setup_1.0.exe`** and run it.

If Windows shows "SmartScreen protected your PC", click **More info → Run anyway**
(the installer is not code-signed yet).

No installation wanted? Download `Ossuary-portable-win64.zip`, unzip it fully and run `Ossuary/Ossuary.exe`.

## Controls

Arrows / WASD — move and attack · Space — wait · Esc — pause · F11 — fullscreen · M — sound · L — language
